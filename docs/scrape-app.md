# 网页内容爬取小工具（Flask）

该工具提供一个简单的网页界面，输入网址即可尝试抓取页面中可能的图表配置或数据片段。

## 使用方式

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 启动服务：

```bash
python app.py
```

3. 在浏览器打开：

```
http://localhost:5000
```

## 使用提示

- 请输入完整网址（或省略协议时自动补全为 `https://`）。
- 工具会在页面 `<script>` 中查找常见图表关键字（如 ECharts/Highcharts/Chart.js）。
- 最多返回 50 条脚本片段，每条最多截取 20,000 字符。

## 注意事项

- 请确保目标网站允许抓取并遵守其使用条款。
- 如果目标页面内容由前端渲染或需要登录，请先用浏览器确认页面是否可直接获取。
- 如果图表数据来自接口，建议结合 DevTools Network 定位真实数据源。
