# 图表数据智能爬取工具（Flask）

该工具提供一个网页界面，输入网址即可自动提取图表数据，并支持 Cookie/Headers/代理等高级选项。

## 使用方式

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 启动服务：

```bash
python app.py
```

3. 在浏览器打开：

```
http://localhost:5000
```

> 启动后会自动打开浏览器页面。

> 默认会在启动时自动检测依赖并尝试安装（可通过环境变量 `AUTO_INSTALL_DEPS=0` 关闭）。

## 使用提示

- 请输入完整网址（或省略协议时自动补全为 `https://`）。
- 工具会解析 `series/data/datasets/xAxis/yAxis` 等常见配置。
- 如果页面需要登录，可在高级设置中粘贴 Cookie 或 Headers。
- 支持自定义正则匹配，以增强复杂页面的识别能力。
- 页面包含基础 CSRF 校验，导出与提交需带上页面生成的隐藏字段。
- 对于 JS 动态渲染页面，可启用“动态爬取”，需本地安装 Playwright。

## 导出功能

- JSON 导出：结构化数据，适合再处理。
- CSV 导出：每个数据块一行，便于快速查看。
- Excel 导出：每个数据块一个工作表，适合进一步分析。
- Word 导出：每个数据块一个表格，方便文档汇报。

## 在线预览

- 页面内置图表预览，可选择折线图/柱状图/饼状图/环形图。
- 预览使用首个可解析的数据块作为示例，适合快速检查数据是否合理。

## 注意事项

- 请确保目标网站允许抓取并遵守其使用条款。
- 如果目标页面内容由前端渲染或需要登录，请先用浏览器确认页面是否可直接获取。
- 如果图表数据来自接口，建议结合 DevTools Network 定位真实数据源。
