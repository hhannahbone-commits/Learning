# 网页内容爬取小工具（Flask）

该工具提供一个简单的网页界面，输入网址与 CSS 选择器即可抓取页面上的文本内容。

## 使用方式

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 启动服务：

```bash
python app.py
```

3. 在浏览器打开：

```
http://localhost:5000
```

## 使用提示

- 请输入完整网址（或省略协议时自动补全为 `https://`）。
- CSS 选择器示例：`.title`、`#main h2`、`div.chart span.value`。
- 仅抓取匹配元素的文本内容，最多返回 50 条。

## 注意事项

- 请确保目标网站允许抓取并遵守其使用条款。
- 如果目标页面内容由前端渲染或需要登录，请先用浏览器确认页面是否可直接获取。
